## LOR.‎ إيه بالظبط

أغلب أدوات الفيديو بتتعامل مع الاجتماع كحاجة بتحصل وبعدين تختفي. بتطلع منها بتسجيل
محدش بيتفرج عليه، وشات محدش بيقراه. LOR.‎ بيتعامل مع الاجتماع كبداية: اللي اتقرر، ومين
عليه إيه، واللي اتقال — كله بيفضل موجود وقابل للبحث بعدها.

اتبنى عشان يكون سهل الدخول زي Google Meet بالظبط — تفتح لينك، تكتب اسمك، تبقى جوّه —
وعشان يعمل الحاجات اللي Meet إما مش بيعملها أو حاططها ورا اشتراك مدفوع.

واتبنى كمان للناس اللي بتتكلم لغتين في جملة واحدة. **"عملت الـ deploy على الـ server"**
دي طريقة كلام حقيقية لناس كتير، وكل أدوات التفريغ الصوتي تقريباً بتخربطها. إن ده يشتغل
صح هدف أساسي هنا، مش إضافة على الهامش.

## المميزات

### المكالمة — `v0.1`

- **تدخل بضغطتين.** `lor.dev/mza-krf-tqn` ← اكتب اسمك ← جوّه. من غير حساب، من غير
  تثبيت، من غير إضافة متصفح.
- **شاشة تجهيز محترمة.** جرّب الكاميرا والمايك، اختار أجهزتك، وشوف مستوى صوتك قبل ما
  حد يسمعك.
- **QR code** تنقل بيه الاجتماع للموبايل في نص المكالمة. وبيتثبّت كـ PWA.
- **متبني للنت الضعيف.** جودة بتتأقلم، مؤشر اتصال صادق لكل مشارك، وزرار **"صوت بس"**
  واضح بيخلي المكالمة شغالة على داتا الموبايل.
- **تحكّم المضيف.** غرفة انتظار، كتم فرد أو الكل، طرد، قفل الروم، نقل صلاحية المضيف.
  والمضيف بيتعرف بكوكي موقّع — برضه من غير حساب.

### كابشنز بتصمد قدام خلط اللغات — `v0.1.5`

أنظمة التعرّف على الكلام العادية بتفشل مع الكلام ثنائي اللغة بطريقة محددة وموثّقة:
بتكتب الإنجليزي بحروف عربية — *"ديبلوي"* بدل *"deploy"* — أو بتترجم بدل ما تفرّغ.
LOR.‎ بيعالج ده على طبقات:

- **تقطيع حسب نشاط الصوت (VAD)**، فالصوت بيتقسم عند حدود الجُمل مش كل 5 ثواني عشوائية.
  القطع في نص الكلمة هو السبب الأول للنتايج المكسّرة.
- **برومبت مخلوط** بيوجّه الموديل إنه يسيب الكلمات اللاتينية بحروفها اللاتينية.
- **قاموس للروم** — تضيف أسامي فريقك ومصطلحاتك التقنية مرة واحدة وتبطل تتخمّن.
- **رندر ثنائي الاتجاه صحيح.** اتجاه السطر بيتقاس من كلماته، مش من أول حرف فيه —
  الجملة العربية اللي بتبدأ بمصطلح إنجليزي تفضل جملة عربية، و`dir="auto"` بيرصّها
  بالمقلوب.
- **مجموعة تقييم مقاسة** في [`eval/captions/`](eval/captions) بتقيس نسبة خطأ الكلمات
  **و** نسبة الحفاظ على خلط اللغات. أي تعديل في كود التفريغ لازم يعرض أرقامه.

## مفاتيح الـ AI

مميزات الـ AI شغالة من أول لحظة على النسخة المستضافة بمفتاح المشغّل، بحصة يومية عادلة
لكل مستخدم. لما الحصة تخلص، LOR.‎ بيوجّهك لمفتاح مجاني بتاعك ويوريك تجيبه إزاي — بياخد
دقيقتين تقريباً.

مفتاحك انت بيتخزّن **مشفّر في متصفحك** وبيتبعت **للمزوّد مباشرة** طول ما الـ CORS
بيسمح، يعني عمره ما بيوصل لسيرفراتنا أصلاً. ولما الطلب يضطر يعدّي علينا، الـ route
بيمرّر ويرجّع من غير ما يسجّل أو يخزّن أو يكاش أي حاجة.
**مفيش مفتاح بيتكتب في قاعدة البيانات أبداً.** شوف [SECURITY.md](SECURITY.md).

المزوّدين المدعومين: Groq · Google Gemini · OpenAI · OpenRouter · Anthropic · Deepgram ·
ElevenLabs، وأي endpoint متوافق مع OpenAI — بما فيهم Ollama أو LM Studio محلياً.

**المكالمة نفسها مش معتمدة على أي حاجة من ده.** من غير مفتاح ومن غير حصة، الفيديو
والصوت ومشاركة الشاشة والشات والسبورة والتسجيل كلهم شغالين عادي.

## البداية السريعة

```bash
git clone https://github.com/Lord-shaban/lor && cd lor
cp .env.example .env.local     # حط بيانات LiveKit و Supabase
npm install && npm run dev
```

افتح <http://localhost:3000>.

محتاج مشروع على [LiveKit Cloud](https://cloud.livekit.io) (الباقة المجانية كفاية
للتطوير) ومشروع على [Supabase](https://supabase.com). الاتنين بياخدوا دقايق ومحدش فيهم
بيطلب كارت.

## الاستضافة الذاتية

> بتنزل في `v0.8`.

```bash
docker compose -f docker/docker-compose.yml up -d
```

بيشغّل تطبيق الويب و LiveKit SFU وسيرفر TURN و Postgres. سيرفر VPS صغير واحد بيكفي
فريق حقيقي. الاستضافة الذاتية مسار أساسي مش إضافة — النسخة المستضافة بتشغّل نفس الكود.

## الإعدادات

| المتغيّر | مطلوب؟ | الوصف |
|---|:---:|---|
| `NEXT_PUBLIC_LIVEKIT_URL` | أيوه | عنوان سيرفر LiveKit، مثال `wss://your.livekit.cloud` |
| `LIVEKIT_API_KEY` | أيوه | مفتاح LiveKit |
| `LIVEKIT_API_SECRET` | أيوه | سر LiveKit |
| `DATABASE_URL` | أيوه | رابط الاتصال بـ Postgres |
| `LOR_HOST_COOKIE_SECRET` | أيوه | السر المستخدم في توقيع كوكي المضيف |
| `LOR_STT_API_KEY` | لأ | مفتاح التفريغ الصوتي للمشغّل. لو فاضي، المستخدمين بيحطوا مفاتيحهم |
| `LOR_LLM_API_KEY` | لأ | مفتاح الـ LLM للمشغّل. لو فاضي، المستخدمين بيحطوا مفاتيحهم |
| `LOR_FREE_STT_SECONDS_PER_USER_PER_DAY` | لأ | حصة التفريغ اليومية لكل مستخدم |
| `LOR_FREE_LLM_TOKENS_PER_USER_PER_DAY` | لأ | حصة الـ LLM اليومية لكل مستخدم |
| `LOR_FREE_STT_SECONDS_GLOBAL_PER_DAY` | لأ | سقف حماية على مستوى السيرفر كله |

القايمة الكاملة في [`.env.example`](.env.example).

## المعمارية

الميديا وكل حالة التطبيق اللحظية بيمشوا على LiveKit. السيرفر بيعمل شغل قصير
(طلب/رد) بس — من غير أي socket طويل بتاعنا — وده اللي بيخلي نفس الكود يشتغل على
serverless وعلى سيرفر واحد مستضاف ذاتياً.

```
┌─────────────┐         media (WebRTC)        ┌──────────────────┐
│   المتصفح   │ ◄───────────────────────────► │     LiveKit      │
│  (Next.js)  │ ◄───── data channel ────────► │  سحابي أو ذاتي   │
└──────┬──────┘   chat · reactions · captions └────────┬─────────┘
       │          whiteboard · notes · knock           │
       │ REST (قصير)                                    │ webhooks
       ▼                                               ▼
┌────────────────────────────────────────────────────────────┐
│  Next.js route handlers                                    │
│  توكن · رومات · دخول · STT proxy · AI · حصص                │
└──────────────────────────┬─────────────────────────────────┘
                           ▼
              ┌───────────────────────────────┐
              │  Postgres (+ pgvector)        │
              │  rooms · transcripts          │
              │  decisions · tasks · usage    │
              └───────────────────────────────┘
```

**الستاك:** Next.js 16 · React 19 · TypeScript · Tailwind 4 · LiveKit · Yjs · tldraw ·
Drizzle · Postgres.
