# Agent instructions

The working agreement for this repository is [`CLAUDE.md`](CLAUDE.md). Read it
before changing anything — it records decisions that are already made, so they do
not get relitigated or quietly broken in a later session.

This file exists because [agents.md](https://agents.md) is becoming the
vendor-neutral name for the same thing, and a tool that looks for `AGENTS.md`
should not conclude the repository has no conventions. There is one document, not
two: anything written here instead of in `CLAUDE.md` is a second source of truth
waiting to disagree with the first.

Human contributors want [`CONTRIBUTING.md`](CONTRIBUTING.md), which covers the
same ground without the parts that are only interesting to an agent.
